📘 Manual de usuario

Guía breve de uso. La aplicación trabaja localmente en el navegador y no requiere npm, Node.js ni conexión a internet.

🚀 1. Inicio rápido

Paso 1: escribe el nombre del expediente en Nombre del expediente.

Paso 2: usa 📄 Agregar PDFs para documentos puntuales o 📁 Agregar carpeta para cargar una carpeta completa.

Paso 3: revisa la bandeja, clasifica cada archivo y ajusta el orden con las flechas ↑ y ↓. Si el tipo documental no está en la lista, elige Otro y escribe de qué se trata.

Paso 4: define si deseas portada y separadores. Luego pulsa 🧩 Consolidar PDF. La barra de progreso mostrará el avance.

🧰 2. Qué hace cada botón principal

📄 Agregar PDFs: permite seleccionar varios PDFs del equipo.

📁 Agregar carpeta: incorpora todos los PDFs detectados dentro de una carpeta y sus subcarpetas.

📂 Abrir proyecto: abre un proyecto JSON guardado. Si el proyecto fue guardado desde esta versión, puede recuperar también los PDFs incrustados.

💾 Guardar proyecto: guarda la organización actual. Para conservar la continuidad sin rutas locales, el archivo JSON incluye el contenido de los PDFs seleccionados.

🧾 Manifiesto HTML: crea una hoja de control del expediente.

🧩 Consolidar PDF: genera el expediente unificado. La portada y los separadores son opcionales y salen sin marca institucional.

🛡 3. Recomendaciones de uso

Trabaja un expediente por caso y usa nombres claros, por ejemplo: Diana_Osorio_Acoso_Fuero_2026.

Antes de consolidar, revisa duplicados, orden documental, clasificación y observaciones. Si usaste Otro, escribe el tipo específico para evitar separadores ambiguos.

Si el expediente es muy grande, el proyecto JSON puede quedar pesado porque conserva los PDFs incrustados. En ese caso, consolida el PDF final una vez tengas la bandeja lista.

La información no se sube a internet. Todo se procesa localmente en el computador del usuario.
