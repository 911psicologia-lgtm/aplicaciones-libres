📖 Manual de instrucciones
Objetivo: Reconstruir las 6 imágenes fracturadas en las caras del cubo.

  1. Libertad total: Puedes armar cada imagen en cualquier cara.
  2. Rotar: Arrastra el fondo para girar el cubo. En móvil: un dedo.
  3. Zoom: Rueda del mouse o pellizco con dos dedos.
  4. Jugar: Toca una pieza para seleccionarla, toca otra para intercambiarlas.
  5. Victoria: Presiona "¡TERMINÉ!" para verificar.
  6. Ayudas: Deshacer, Mezclar, Pista inteligente y Auto-check disponibles.
