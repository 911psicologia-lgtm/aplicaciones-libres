Ruta de trabajo

La aplicación no obliga a escribir todo de una vez: organiza el proceso por momentos de decisión.

1

Configura

Define título, pregunta, objetivos y deriva central.

2

Problematiza

Construye los seis puntos de delimitación relacional.

3

Consolida

Integra justificación, estado del arte, marco y exporta.

Momento 1 · Mapa inicial

Define la identidad mínima del protocolo. Estos datos alimentan todos los prompts.

Estas referencias no limitan a la IA: son una base de partida. El prompt le exige buscar, verificar e integrar fuentes adicionales reales cuando hagan falta.

🧠 Momento 1 también puede generar el problema

Desde aquí puedes producir un prompt específico para construir el planteamiento del problema a partir del título, idea, pregunta, objetivo y referencias iniciales; luego pegas la respuesta en la app para que se distribuya en sus seis campos.

Momento 2 · Planteamiento del problema

Seis puntos para delimitar sin volver lineal el fenómeno. Cada caja tiene una función precisa.

1Caracterizar → 2Definir → 3Cifrar → 4Causar → 5Consecuenciar → 6Cerrar bucle

Momento 3 · Fundamentación

Justificación, estado del arte y marco teórico ya no aparecen como una lista pesada, sino como módulos de trabajo.

📝 Justificación

Razón teórica, social, metodológica y práctica.

📚 Estado del arte

Tendencias, vacíos, tensiones y lugar del estudio.

🧠 Marco teórico

Categorías, autores, relaciones conceptuales y criterios de interpretación.

🔎 Banco de referencias

Fuentes suministradas, generadas por IA y desduplicadas para exportación.

Momento 4 · Metodología y coherencia

El método se escribe como arquitectura del estudio: enfoque, diseño, participantes, técnicas, análisis, ética y criterios de rigor.

Momento 5 · Prompts académicos

Selecciona una tarea. Cada prompt incluye modo antialucinación, estructura, evidencias y salida esperada.

⬇️ Retorno de IA hacia la app

Pega la respuesta JSON o texto estructurado que te entregue la IA. La app distribuirá el contenido en los campos correspondientes y agregará las referencias al banco consolidado.

Momento 6 · Protocolo consolidado

Documento ensamblado con la información diligenciada. Puede copiarse o exportarse.

Presiona “Generar protocolo consolidado” para ver el documento.
