# Auditoría disciplinar v3.1

## Criterio

Las disciplinas no reemplazan los campos problemáticos ni atribuyen profesiones modernas a autores antiguos. Cada vínculo distingue entre aporte directo, antecedente histórico, influencia posterior, problema compartido, cruce interdisciplinario y lectura contemporánea posible.

Una tarjeta puede tener varias relaciones publicables y, simultáneamente, una relación distinta todavía pendiente. Los resultados de la aplicación excluyen únicamente el vínculo provisional, no la tarjeta completa.

## Cruces

La intersección emplea lógica AND: una idea debe poseer un vínculo publicable con todas las disciplinas seleccionadas. Esta regla evita que el cruce sea una mera suma de etiquetas.
