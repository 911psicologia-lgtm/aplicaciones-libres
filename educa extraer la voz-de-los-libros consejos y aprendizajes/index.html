Nueva lectura

Paso 1 de 3 · Intención

¿Qué necesitas hoy?
Elige una sola intención principal. Esto ayuda a que la lectura tenga foco.
O cuéntame con tus palabras:

Lectura para una situación

Identidad clara y cuidado del destinatario

Define quién pide, quién escucha y quién acompaña.
Si dejas este campo vacío, la IA trabajará desde la situación concreta y no arrastrará automáticamente los autores favoritos del perfil.
La lectura se dirigirá al destinatario indicado. Si es menor de edad, el prompt usará lenguaje sencillo, protector y no alarmante. En situaciones médicas no reemplaza al equipo de salud.

Fuentes de lectura

Paso 2 de 3 · Libros y autores

Escribe libros, autores o temas. Si no tienes fuentes, la IA elegirá referencias reales y pertinentes.
💡 Si tienes archivos o textos, los usarás en la IA al final. Si no escribes libros ni autores, el prompt pedirá fuentes existentes y adecuadas; no debe inventar obras.

Extracción

Paso 3 de 3 · Ideas y enfoque

Elige el modo de lectura. Esto define cómo se transformará el contenido.
Ideas centrales extrae aprendizajes, frases memorables y recomendaciones. Narrativa resumida debe parafrasear, sin copiar pasajes de obras protegidas.
Si lo dejas vacío, la IA elegirá la forma narrativa más clara para comprender el tema.
¿Cuántas tarjetas quieres recibir?
La app pedirá 20 ideas/tarjetas y no recortará la respuesta si llegan más tarjetas válidas.
Recomendado para estabilidad: 30–100 tarjetas. 150 es avanzado. 200 o más puede tardar, cortarse o fallar; mejor dividir por bloques.
Elige cómo quieres escuchar cada tarjeta.
Neto: idea central. Contexto: significado para ti + frase. Ambos: todo junto. Acción: qué hacer, preguntar o practicar.

Ejemplo rápido

NetoLa obra habla de una decisión difícil.
ContextoEsto puede ayudarte a mirar tu situación con más calma. “Elegir también es cuidar.”
AcciónEscribe dos opciones y una consecuencia de cada una.

🌱 Perfiles
        
Después del splash aparece “¿Quién está aquí hoy?” cuando hay perfiles guardados. Cada perfil conserva su biblioteca, sesiones, favoritos, playlists, autores, tono y preferencias. Desde Inicio o Configuración puedes entrar a Usuarios y perfiles para cambiar, crear o editar nombres. La app no guarda perfiles vacíos y evita nombres genéricos como “Usuario” para que el audio no suene impersonal.

      

      
🏠 Inicio personalizado
        
La pantalla inicial funciona como hub: Continuar escuchando, Crear nueva lectura, Lectura para una situación, Mi biblioteca, Playlist y Configuración. Backup, Importar, Manual, Tema, Ajustes, Ayuda y Volver al inicio viven en una pantalla propia de Configuración, sin menú lateral.

      

      
✨ Crear nueva lectura
        
Crear nueva lectura abre dos caminos: Lectura libre, para libros, autores, textos o temas; y Lectura para una situación, para indicar quién pide, quién escucha y quién acompaña. En intención se elige una sola categoría principal para mantener foco. Para estabilidad de la IA se recomiendan 30–100 tarjetas; 150 es avanzado y 200 o más puede cortarse.

      

      
🧠 Modos de lectura
        
Ideas centrales extrae aprendizajes, frases propias y recomendaciones. Narrativa resumida resume una obra en capítulos, escenas o partes ordenadas; si es académica, sigue sus argumentos sin saltos. Historia para comprender no resume: convierte una obra, tema o concepto en una historia pedagógica nueva, con inicio y cierre ligados a las fuentes. Guía académica explica conceptos y relaciones con más rigor.

      

      
🧩 Neto / Contexto / Ambos / Acción
        
Neto muestra la idea central del libro, autor, tema o situación. Contexto muestra qué significa para la persona y cierra con frase memorable. Ambos une idea central, contexto y frase. Acción muestra solo qué hacer, preguntar o practicar.

      

      
🎁 ¿Qué hay para mí?
        
Analiza lecturas, favoritas, categorías y escuchas para devolver una recomendación breve del día. Puede generar un recorrido estable para hoy o una sorpresa aleatoria con sentido.

      

      
🌙 Una historia para…
        
Permite crear una historia nueva, mejorar una historia propia o continuar un relato. Usa destinatario, edad, argumento base, personajes, referentes, moraleja, tono y final deseado. Si aparecen referentes protegidos, la app debe transformarlos en una historia original.

      

      
🛡️ Límites y privacidad
        
La app guarda datos en este dispositivo y permite backup JSON. No sincroniza en la nube, no genera PDF, no usa API interna, no exporta Word y no usa OCR ni cámara. Sus lecturas acompañan reflexión y estudio; no sustituyen atención profesional.

      

      
🫶 Lectura para una situación
        
Permite crear lecturas para ti, otra persona o un grupo. La app separa solicitante, destinatario y acompañante para evitar saludos confusos. En esta pantalla los autores favoritos del perfil no se arrastran automáticamente: solo se usan fuentes escritas para el caso o sugerencias abiertas pedidas por ti. Si el destinatario es menor, el prompt pide lenguaje sencillo, protector, no clínico, no alarmante y sin promesas médicas absolutas.

      

      
🎧 Escuchar y reproductor global
        
Dentro de la sesión se mantiene el reproductor-tarjeta superior y, cuando ya hay lectura activa, aparece también una mini-barra inferior con anterior, play/pausa y siguiente para poder pausar mientras lees tarjetas más abajo. Fuera de la sesión, esa misma barra permite continuar escuchando mientras navegas.

      

      
🗄️ Biblioteca
        
Cada JSON pegado queda como sesión. Puedes buscar, filtrar por tema, abrir lecturas, marcar favoritas, reproducir sesiones y detectar metadatos como cantidad visible/guardada, fuentes y favoritos. Backup e Importar se gestionan desde Configuración.

      

      
🎼 Playlists
        
Mi biblioteca está organizada en tres secciones: Sesiones, Playlists y Favoritas. Las playlists guardadas viven en Mi biblioteca → Playlists, donde puedes reproducirlas, renombrarlas o eliminarlas sin borrar las sesiones originales. Para crear una personalizada, entra a Sesiones, toca “Crear playlist” o mantén presionada una sesión, selecciona varias sesiones, ponles nombre y guárdalas.

      

      
↗ Compartir
        
Un consejo se comparte como tarjeta, imagen, texto o enlace. Una sesión completa se comparte como archivo JSON desde el reproductor. El lector interno sigue trabajando tarjeta por tarjeta.

      

      
💾 Backup e importar
        
Backup descarga biblioteca, perfil y metadatos principales. Importar recibe un backup o una sesión compartida. Los datos viven en este dispositivo; por eso conviene respaldar cada cierto número de sesiones nuevas.

      

      
⚙️ Configuración
        
La app ya no usa menú hamburguesa. En el inicio toca Configuración para abrir una pantalla completa con Backup, Importar, Manual, Tema, Ajustes del perfil, Usuarios y perfiles, Ayuda y Volver al inicio. Así se evitan superposiciones sobre sesiones y playlists.

      

      
📲 Instalar como app
        
Desde Chrome puedes instalarla en la pantalla de inicio. Funciona sin conexión para leer, escuchar sesiones guardadas y gestionar biblioteca; el motor IA requiere conexión.
