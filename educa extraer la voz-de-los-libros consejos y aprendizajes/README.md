# Voz de los Libros — v0.10.28

Versión con cuarto camino: **¿Qué hay para mí?**

## Cambios principales

- En “Crear nueva lectura” ahora hay cuatro caminos:
  - 📚 Lectura libre
  - 🫶 Lectura para una situación
  - 🌙 Una historia para…
  - 🎁 ¿Qué hay para mí?

## Nuevo módulo “¿Qué hay para mí?”

Este módulo analiza señales locales de la biblioteca:

- lecturas guardadas;
- favoritas;
- categorías frecuentes;
- tipo de sesiones;
- escuchas registradas;
- últimas lecturas;
- ideas memorables.

Con eso genera un recorrido breve para el día.

## Acciones disponibles

- **Recomendarme algo para hoy**: crea un recorrido estable del día desde favoritas, categorías y lecturas recientes.
- **Sorpréndeme**: crea una mezcla aleatoria con sentido.
- **Volver a favoritas**: usa el repaso breve de favoritas.
- **Ir a mi biblioteca**: abre la memoria viva de lecturas.

## Funcionamiento

No usa IA interna ni nube. La recomendación se construye localmente desde la biblioteca guardada en este dispositivo.
