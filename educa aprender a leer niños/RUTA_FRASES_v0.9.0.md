# Ruta de frases · v0.9.0

**Frases vivas** se habilita después de superar P. Cada escalera conserva una sola frase durante cuatro pasos para reducir carga cognitiva y retirar apoyo gradualmente.

| Se desbloquea tras | Frase | Secuencia |
|---|---|---|
| P | mamá ama a papá | modelo → completar → ordenar → leer en escena |
| S | susi amasa masa | modelo → completar → ordenar → leer en escena |
| L | lola usa la lupa | modelo → completar → ordenar → leer en escena |
| N | nana ama la luna | modelo → completar → ordenar → leer en escena |
| T | tito toma sopa | modelo → completar → ordenar → leer en escena |
| D | nana toma el dado | modelo → completar → ordenar → leer en escena |
| Jardín de Palabras | lola nota una paloma | modelo → completar → ordenar → leer en escena |

En los pasos 2 y 3 el audio de la frase completa ya no se reproduce automáticamente: queda en el botón de oído como ayuda voluntaria. Si se usa, la respuesta correcta se registra como asistida. En el paso 4 la app registra si se pidió ayuda, pero no atribuye una puntuación automática a la lectura oral.
