# Ajustes UI v0.7.2 · navegación visual y sendero guiado

## Cambios aplicados
- Se reemplazó la línea recta del mapa por un **sendero conectado** que une cada lección según el orden real de progresión.
- Se añadieron **números de secuencia** sobre cada nodo para reforzar el recorrido.
- El siguiente punto recomendado ahora queda mejor señalado con **pulso visual** y flecha.
- La pantalla de cierre de aventura fue compactada para niños prelectores:
  - recompensa del cofre en formato de icono,
  - bloque “lo que sigue” más visual,
  - navegación inferior con botones circulares: volver, menú, libro, repetir y siguiente.
- Se actualizó la versión visible a **0.7.2** y el cache del service worker para forzar la recarga del frontend.
