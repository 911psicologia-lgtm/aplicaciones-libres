📘 Manual de Usuario

Flujo recomendado: 🏠 Inicio → (📋 elegir empresa) → 🧾 elegir presupuesto → ➕ Agregar Producto → 💾 Guardar → 📤 Exportar

1) Empresas

En 📋 Empresas Registradas puedes:

• ➕ Nueva empresa crea una empresa con valores sugeridos (IPC, AIU, IVA, Otros Impuestos).

• 📂 Abrir muestra presupuestos guardados y permite crear uno nuevo.

• ✏️ edita la empresa.

• 🗑️ elimina la empresa (incluye presupuestos y productos).

2) Presupuestos

Al abrir o crear un presupuesto verás, en este orden:

• Nombre del Presupuesto *

• Intervalo (Inicio – Fin)

• 💾 Guardar (guarda el avance)

• ➕ Agregar Producto (abre el modal)

• 🧮 Aplicar IPC (asigna el IPC sugerido de empresa a todos los productos del presupuesto)

• 🗑️ Limpiar (solo el presupuesto actual)

3) Productos

Cada producto puede tener sus propios porcentajes: % IPC, % IVA, % AIU y Otros Impuestos (%).

Importante: “Otros Impuestos” NO se aplica automático por empresa; se define por producto.

En la tabla: ✏️ editar, 🗑️ eliminar.

4) Exportación

En 📤 Exportar puedes descargar:

• 📊 Excel (sin fórmulas) con tabla + totales.

• 🌐 Reporte HTML listo para enviar o imprimir.
