📖 Manual de Vuelo
⚡ Verbos (Base)
Pasado Simple, Participio, Infinitivo, Traducción de verbos irregulares y regulares.
⏪ Past Perfect
HAD + Past Participle · Para acciones ANTERIORES a otra acción pasada. Ej: She had left before I arrived. · Negativo: hadn't · Pregunta: Had she...?
🕰️ Used To
Afirmativa: used to + verbo base · Negativa: didn't use to · Pregunta: Did... use to? · Regla: con did/didn't se escribe use to (sin -d)
⭐ Presente Perfecto
HAVE/HAS + Participio · already, just, yet, ever, never, since, for
🔄 Perfecto Continuo
HAVE/HAS + BEEN + -ING · for, since, all day, lately, recently
🚀 Formas de Futuro
will (predicción) · be going to (plan) · present continuous (arreglos) · will be/will have (futuro perfecto)
🎲 Condicionales 0-3
0: If + present, present · 1: If + present, will · 2: If + past, would · 3: If + had, would have
🔵 Voz Pasiva
be + past participle · presente, pasado, perfecto. Ej: The book was written by her.
💬 Reported Speech
said that / told me to · cambios de tiempo verbal y pronombres.
🔗 Relative Clauses
who (personas) · which/that (cosas) · where (lugares) · whose (posesión)
🎩 Modales Avanzados
must/might/can't + infinitivo · must/might/can't have + participio (deducción pasada)
🔀 Gerundios & Infinitivos
enjoy/avoid/finish + -ING · want/decide/hope + to · ¡sin confundirlos!
