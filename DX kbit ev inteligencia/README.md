# KBIT Protocolo Cognitivo v0.11.0

## Novedad central
- Hoja de anotación K-BIT digitalizada a partir de la plantilla original aportada.
- Inyección automática de datos del evaluado, 1/0 por reactivo, respuestas de Matrices, totales y puntuaciones finales.
- Descarga de la hoja cumplimentada en PDF directo de dos páginas y DOCX A4: página 1 idéntica a la plantilla original cumplimentada; página 2 con respuestas literales registradas.
- La plantilla original vacía se conserva como documento de referencia.
- Expediente completo en DOCX/PDF/HTML: portada institucional + informe técnico + contextual seleccionado + protocolo detallado + hoja cumplimentada + firma/anexos.
- El protocolo detallado continúa siendo la fuente para respuestas textuales, tiempos y observaciones que no caben en la hoja original.
