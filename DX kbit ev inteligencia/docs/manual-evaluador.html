Manual del evaluador

Protocolo Cognitivo K-BIT · v0.3.0

Este documento explica el uso de la aplicación. Las consignas, puntos de inicio, reglas de retorno, discontinuación y criterios específicos de corrección del K-BIT se incorporarán posteriormente a partir del material autorizado. Esta versión no los inventa ni los sustituye.

1. Antes de comenzar

1.1. Verifique el dispositivo. Abra la aplicación desde Cloudflare Pages en un navegador actualizado. Los casos se guardan localmente en ese navegador.
1.2. Mantenga separados los estímulos. La aplicación registra respuestas y puntuaciones; los estímulos se muestran externamente por el evaluador.
1.3. Proteja la información. Los respaldos JSON contienen información identificable. Guárdelos en un entorno seguro.

2. Crear el caso

Desde Inicio, seleccione Nueva evaluación. Registre los datos reales del evaluado en la aplicación. La fecha de aplicación aparece con la fecha actual y puede modificarse. Al ingresar la fecha de nacimiento, el sistema calcula la edad cronológica en años, meses y días y selecciona automáticamente el intervalo normativo.

La aplicación genera un alias para IA. Ese alias puede editarse. El paquete de IA excluye nombre, documento, institución específica y fecha exacta de nacimiento.

3. Contextualización

Seleccione el contexto de evaluación y registre:

  • motivo concreto de evaluación;
  • datos relevantes del caso;
  • información contextual adicional necesaria para interpretar los resultados.
Si la información será utilizada en un flujo con IA, evite introducir identificadores directos dentro de los campos narrativos.

4. Aplicación multipantalla

La aplicación presenta una pantalla de registro por reactivo. El evaluador muestra el estímulo por separado, escucha la respuesta y registra:

CampoUso
RespuestaTranscripción o síntesis de la respuesta.
0Respuesta calificada como incorrecta.
1Respuesta calificada como correcta.
No administradoReactivo no presentado por razones de administración.
ObservaciónLatencia, repetición, autocorrección, conducta u otra incidencia.

Atajos disponibles cuando el cursor no está dentro de un campo de texto: 0, 1, ←, →.

Definiciones se activa automáticamente desde los 8 años, de acuerdo con la lógica ya utilizada por la versión de trabajo de la aplicación.

5. Revisión y puntuación

Antes de interpretar, revise el número de respuestas correctas, incorrectas, no administradas y sin registro. Mientras se completa el manual integrado, la pantalla permite añadir créditos o ajustes basales y, excepcionalmente, introducir un bruto final manual.

No utilice un bruto manual sin verificar el protocolo. La opción existe para mantener compatibilidad con la corrección profesional cuando las reglas de inicio, retorno o discontinuación impliquen créditos no representados por los reactivos visibles.

6. Resultados automáticos

Una vez disponibles la edad y los brutos, la aplicación utiliza las tablas incorporadas del Apéndice C:

  • C.1: bruto → puntuación típica por edad;
  • C.2: suma de típicos → CI compuesto;
  • C.3: bandas de error e intervalos de confianza;
  • C.4: percentiles, categorías descriptivas y eneatipos;
  • C.5: criterio de significación para la discrepancia verbal–no verbal.

7. Informes

7.1. Informe técnico

Se genera localmente con identificación real, motivo, procedimiento, resultados, comparación de escalas, interpretación técnica, limitaciones y conclusión.

7.2. Informe contextualizado

Puede utilizar un borrador local o un borrador de IA. Para IA, copie únicamente el prompt anonimizado. La aplicación exige no inferir causalidad y diferenciar datos observados, condiciones asociadas e hipótesis.

Los informes pueden exportarse como HTML enriquecido, TXT, DOC compatible con Word y PDF mediante la función de impresión del navegador.
