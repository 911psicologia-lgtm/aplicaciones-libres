# Presencia v8 · Guía corporal

Aplicación HTML5 multiarchivo y PWA lista para Cloudflare Pages.

## Recorrido guiado

1. **Entrada directa a la guía:** la pantalla principal prioriza continuar una sesión.
2. **Orientación opcional:** cuatro pausas personales que pueden completarse, dictarse o saltarse.
3. **Ocho sesiones:** orientación sencilla, ejemplo, lectura en voz, práctica animada y cierre.
4. **Nota al final:** la escritura nunca interrumpe la práctica y no es obligatoria.
5. **Informe multiformato:** página HTML autónoma, documento DOC para Word, impresión/PDF y datos JSON.

## Funciones

- Lectura en voz de cada guía con velocidades 1×, 1.5×, 1.8× y 2×.
- Prácticas visuales sin movimiento físico, con temporizador de 1, 3 o 5 minutos.
- Dictado por voz para notas y registros cuando el navegador lo permite.
- Bitácora de sesiones y estadísticas descriptivas.
- Impulso con IA externa mediante copia y validación de JSON 4.0.
- Múltiples procesos, versiones y respaldo global.
- Caso demostrativo completo bajo el seudónimo **Andrés**.
- Instalación PWA, diseño responsive y almacenamiento local.

## Alcance

Presencia es una herramienta educativa de atención, representación mental y registro. No diagnostica, prescribe rehabilitación ni indica movimientos. El relato autobiográfico de Joe Dispenza se conserva como caso de origen y no se presenta como evidencia clínica de reparación corporal. Toda práctica física debe proceder del plan profesional individual.

## Publicación

Descomprime el ZIP y sube su contenido completo a Cloudflare Pages. `index.html` debe quedar en la raíz.
