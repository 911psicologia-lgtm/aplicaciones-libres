Nota técnica honesta

En modo local, RizoLink guarda la biblioteca en este navegador. Para que los enlaces cortos funcionen públicamente para cualquier persona, se requiere desplegar el backend incluido en la carpeta worker usando Cloudflare Workers + KV o una base de datos.

La app ya deja lista la interfaz premium, la biblioteca, el QR, la edición y el modelo de datos para crecer sin rehacer el diseño.
