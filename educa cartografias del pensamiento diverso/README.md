# Cartografías del Pensamiento v3.9

Aplicación PWA estática consolidada en la revisión técnica **3.9.1**, con **1474 ideas**, **1474 expedientes**, **1474 capas históricas**, **37 colecciones**, reproducción continua, búsquedas, favoritas, intereses, conexiones, rizomas y exploración disciplinar.

## Cartografía AJ

La colección **Cartografía AJ · Complejidad, bioética e investigación latinoamericana** contiene 14 ideas: exactamente dos por cada uno de siete autores.

- Estanislao Zuleta.
- Carlos Jesús Delgado Díaz.
- José Alonso Andrade Salazar.
- Roberto Rivera Pérez.
- Carlos Eduardo Maldonado.
- Emilio Roger Ciurana.
- Raúl Domingo Motta.

La revisión 3.9.1 reforzó fuentes, atribuciones, relaciones disciplinares y protecciones frente a elementos DOM inexistentes. `index.html` está directamente en la raíz para despliegue en Cloudflare Pages.
