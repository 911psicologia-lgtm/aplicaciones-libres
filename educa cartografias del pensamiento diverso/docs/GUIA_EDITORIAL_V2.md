# Guía editorial v2

## Principio
Cada tarjeta debe situar una idea en tiempo, territorio, problema, aporte y evidencia, sin convertir incertidumbres en hechos.

## Dos temporalidades
- **Doce periodos editoriales** organizan investigación, cobertura y auditoría.
- **Siete macroetapas de navegación** mantienen una experiencia legible para el usuario.

## Tipos de entrada
Autoría, tradición, concepto, obra, debate, escuela, acontecimiento, ruta de traducción, ruptura epistemológica, encuentro intercultural, método y portal contextual.

## Familias visuales
El campo `family` dejó de funcionar como etiqueta libre. La descripción previa se conserva en `legacyFamily`, mientras `visualFamilyId` selecciona una de dieciséis familias controladas.

## Evidencia
A, A-B, B, B-C y C se acompañan de `evidenceNature`, `controversyStatus` y cautela editorial.

## Fuentes
Una fuente con URL procede de un lote de investigación; una obra ancla sin URL permanece como referencia bibliográfica pendiente de edición o enlace. Nunca se crea una referencia ficticia para completar un campo.

## Estados
`candidate`, `researching`, `verification_pending`, `editorially_approved`, `integration_pending`, `published`, `revision_required`, `reserved`, `discarded`.
