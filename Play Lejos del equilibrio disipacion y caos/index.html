Manual de ayuda

Cerrar

Mueves la nave tocando o arrastrando. Las letras aparecen alrededor del atractor central. Captura letras para completar las palabras del nivel. Cuando todas las palabras estén completas, el nivel se cierra y el sistema entra en transición.

  • ⭕ Círculo parcial: reduce una parte del rizoma (disipación local).
  • ⚪ Círculo blanco: borra todo el campo (disipación global).
  • 🌀 Atractor extraño: al capturarlo, succiona todo el campo y hace emerger una palabra clave por tiempo limitado.
  • ⏸ Pausa: suspende el sistema sin perder el estado.
  • Guardar: almacena nivel, puntaje, tiempo y progreso de letras.

Nota: el atractor extraño no “ayuda” necesariamente: crea vacío, presión temporal y reconfiguración.
