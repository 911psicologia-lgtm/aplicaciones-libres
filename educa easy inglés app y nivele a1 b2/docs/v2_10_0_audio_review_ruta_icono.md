# v2.10.0 · Repaso auditivo ampliado + ruta 🛣️

## Cambios
- El ícono 🎧 ahora abre un panel compacto de repaso auditivo.
- El usuario puede elegir:
  - Palabras y frases.
  - Diálogos animados.
- Se conservó la lógica original de palabras/frases al elegir esa opción.
- Para diálogos animados se puede elegir:
  - 🔊 Inglés.
  - EN–ES.
  - Normal / Lento.
- Se agregó barra compacta de reproducción con Pausa/Reanudar, Siguiente y Detener.
- Se agregaron claves independientes:
  - `audioReviewSource`
  - `audioReviewVoiceMode`
  - `audioReviewSpeed`
- La barra superior queda en orden:
  ← → 👤 🏠 🛣️ 🧠 🎧 📘 ☰
- 🛣️ abre el detalle de mundos y enfoca el mundo pendiente/actual sin iniciar lección.

## Preservación
No se modificaron progreso, evaluaciones, videos, diálogos integradores, módulo 🎬 Diálogo animado ni localStorage existente.
