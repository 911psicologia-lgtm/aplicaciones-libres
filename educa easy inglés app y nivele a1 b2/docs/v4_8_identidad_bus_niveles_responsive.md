# v4.8 · Identidad bus, niveles A1-B2 y ajustes responsive

- Se preserva el logo/loro como identidad general de la app.
- Se consolida el bus como identidad de ruta, carretera y mundo en curso.
- El cohete deja de ser icono de estaciones internas; queda reservado para logros o estímulos secundarios.
- Las microlecciones del mundo se presentan como estaciones de un ramal sinuoso con estados visuales: completada, actual y bloqueada.
- Se reemplaza el icono de salida del dock por SVG inline para evitar que en móviles aparezca como cuadro con X.
- Se añade botón de niveles A1/A2/B1/B2 antes de salir; el nivel activo se muestra con énfasis neón.
- Se añaden accesos directos superiores a Diccionario y Biblioteca dentro de la pantalla unificada para evitar que Biblioteca quede demasiado abajo en móvil.
- Se ajusta la barra inferior para caber mejor en celular, con doble fila solo en pantallas muy estrechas.
