# v4.18.4 · Multiusuario y salida limpia

Cambios:
- Salir ya no marca al usuario activo como no configurado.
- Salir guarda el progreso del usuario actual y lleva a la pantalla completa de selección/creación de usuario.
- La pantalla de acceso muestra memoria de últimos usuarios locales.
- Al escribir un nickname existente, se carga su estado propio.
- Al escribir un nickname nuevo, se crea un usuario limpio desde cero.
- Cada usuario conserva su propio progreso, ruta, mundo, ejercicios y conversaciones.
- Se evita que el usuario nuevo herede los mundos del usuario anterior.
- Se actualiza versión/cache a 4.18.4.
