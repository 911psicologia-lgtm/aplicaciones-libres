# v4.18.5 · Diálogo integrador interactivo

Cambios:
- El diálogo básico queda como flujo interactivo: escuchar → enfocar respuesta → elegir → avanzar al siguiente turno.
- Se elimina el feedback amplio “Bien. Escucha tu respuesta…” para evitar invasión visual.
- Se agrega instrucción visible breve bajo la cabecera del diálogo.
- Al presionar escuchar, se ilumina y desplaza hacia “Tu posible respuesta”.
- Después de respuesta correcta, la opción queda marcada en verde y el sistema avanza al siguiente turno.
- La barra inferior del diálogo queda estandarizada: ← / 🛣️ / →.
- Se elimina el botón redundante “Continuar donde iba”.
- La flecha izquierda aparece siempre.
- El diálogo integrador profundo se ajusta a la misma lógica: escena activa → elegir respuesta → avanzar.
- Los chulos/checks de respuesta correcta se estandarizan en verde.
- Se actualiza versión/cache a 4.18.5.
