# Sistema de inmersión situada v2.0

Esta versión reorganiza la app alrededor de capas invisibles de apropiación del lenguaje: descubrir, nombrar, usar, interactuar, explicar y conectar.

No se muestran niveles CEFR al usuario, pero la progresión situada toma como referencia una expansión gradual desde el mundo vivido hacia una comunicación más autónoma.
