# v4.11.0 · Modo narrativo de ruta completa

Cambios:
- Si una carretera principal queda 100% completada, el bus ya no anima solo el último tramo.
- Ahora recorre narrativamente toda la ruta desde el primer mundo hasta el último.
- Si el mundo interno/submundo queda 100% completado, el bus también recorre todo el ramal de estaciones.
- Si la ruta no está completa, se conserva la lógica anterior: animar solo el tramo actual.
- Se mantiene el trazo sinuoso aprobado.
- Se actualiza versión/cache a 4.11.0.
