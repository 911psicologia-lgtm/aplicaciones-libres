# v2.9.3 · Limpieza UX preservativa

## Cambios aplicados
- Se quitaron los accesos visibles al Tour guiado: menú, portada y manual.
- El auto-tour quedó desactivado para evitar bloqueos.
- Se compactaron las notificaciones: ahora solo queda una visible y breve.
- Se corrigió “Let me do the laundry” → “Déjame lavar la ropa”.
- Se cambió “La app dice…” por “Alguien dice…” en evaluación conversacional.
- Se homogeneizaron opciones de diálogo: todas mantienen traducción.
- Se compactó el modal de videos: texto breve y botones Abrir/Cerrar juntos.
- Se agregó pulso visual suave para elementos desbloqueados.

## Preservación
No se tocaron bancos de ejercicios, avance, evaluación, diccionario ni traducción progresiva.
