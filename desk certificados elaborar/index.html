⚙ Configurar Google Apps Script
Configuración única de 3 minutos. Usa tu cuenta Google existente — sin costos ni cuentas nuevas.
1
Ve a script.google.com e inicia sesión con tu cuenta Google. Haz clic en Nuevo proyecto.
2
Borra todo el código que aparece y pega el siguiente script completo:
function doPost(e) { try { var payload = JSON.parse(e.postData.contents); var to = payload.to; // Subject viaja en base64 para preservar tildes, ñ y caracteres especiales var subject = payload.subjectB64 ? decodeURIComponent(escape(Utilities.newBlob(Utilities.base64Decode(payload.subject)).getDataAsString())) : payload.subject; var html = payload.htmlBody; var replyTo = payload.replyTo || ''; var name = payload.senderName || 'CertiFlow'; if (!to || !subject || !html) { return resp({status:'error', msg:'Faltan campos requeridos'}); } var opts = { htmlBody: html, name: name }; if (replyTo) opts.replyTo = replyTo; GmailApp.sendEmail(to, subject, '', opts); return resp({status:'ok', to: to}); } catch(err) { return resp({status:'error', msg: err.toString()}); } } function doGet(e) { return resp({status:'ok', msg:'CertiFlow GAS activo'}); } function resp(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
3
Haz clic en Implementar → Nueva implementación. En "Tipo" selecciona Aplicación web. En "Ejecutar como" elige Yo (tu email). En "Quién tiene acceso" elige Cualquier usuario. Haz clic en Implementar.
4
Google mostrará la pantalla "Autorizar acceso". Haz clic en "Revisar permisos" y selecciona tu cuenta Gmail.

⚠ Pantalla "Google no ha verificado esta aplicación"
Es completamente normal para scripts personales. Google la muestra porque el script accede a Gmail, pero al ser tu propio script en tu propia cuenta, es 100% seguro.

Para continuar: haz clic en "Avanzado" (enlace pequeño abajo a la izquierda) → luego en "Ir a [nombre de tu proyecto] (no seguro)" → y finalmente en "Permitir".
5
Copia la URL de la aplicación web que aparece (empieza con https://script.google.com/macros/s/) y pégala en el campo de CertiFlow.
6
Haz clic en "Probar conexión" para verificar que todo funciona correctamente. Deberías ver el indicador en verde.
📎 Adjunto PDF incluido: El script incluye soporte para adjuntar el PDF del certificado a cada correo. El PDF se genera en el navegador y se envía codificado — no se almacena en ningún servidor externo.
⚠ Privacidad: El script vive en tu cuenta Google y envía desde tu Gmail. CertiFlow nunca ve ni guarda tus credenciales. La URL del script es el único dato necesario. Esta autorización es permanente — no necesitas repetirla.

Manual de Usuario

Guía completa de uso de CertiFlow Pro — Generador de certificados institucionales.

🚀 Primeros pasos
1
Configura el evento (Paso 1 — General)
Ingresa el nombre de la institución, el tipo de certificado, el evento, fechas, ciudad y modalidad. Todos los datos que aparezcan aquí se autocompletarán en el certificado. Puedes usar el botón 📋 Datos de ejemplo para ver cómo funciona.
2
Elige tamaño y plantilla (Paso 2)
Selecciona el formato de página (Carta horizontal es el más común para certificados) y una de las 11 plantillas visuales disponibles. La plantilla "Con Patrocinadores" incluye una franja inferior donde se muestran los logos de aliados o patrocinadores. Puedes personalizar los colores principal y de acento para adaptar la plantilla a tu identidad institucional.
3
Carga logos y configura firmas (Paso 3)
Puedes cargar entre 1 y 6 logos — usa los botones + Slot y − Slot en la cabecera de la sección para agregar o quitar espacios de logo. El slider "Tamaño del logo" ajusta el tamaño en todos los logos a la vez. Para las firmas, puedes agregar tantas como necesites con el botón + Agregar firma. Cada firma puede tener imagen escaneada, nombre, cargo y dependencia.
💡 Consejo: Las imágenes de firma funcionan mejor con fondo blanco o transparente, escaneadas a 300 DPI y recortadas ajustadamente.
👥 Gestión de participantes
4
Agregar participantes manualmente
En el Paso 4, usa el formulario superior para agregar uno a uno. Solo el nombre es obligatorio; el email es necesario si deseas enviar certificados por correo.
5
Carga masiva por CSV
Descarga la Plantilla CSV incluida, ábrela en Excel o Google Sheets, completa los datos y guárdala como CSV. Luego arrástrala a la zona de carga o haz clic en ella. La app validará el archivo y mostrará cuántos registros se cargaron.
💡 Columnas del CSV: nombre, email, documento, rol, codigo
Solo nombre es obligatorio. Los demás son opcionales.
📝 Texto del certificado
6
Usar un modelo base (Paso 5)
Selecciona uno de los 7 modelos de texto prediseñados (asistencia, participación, aprobación, ponencia, jurado, conferencista, tallerista). El texto se carga automáticamente y puede editarse libremente.
7
Usar marcadores dinámicos
Haz clic en cualquiera de los marcadores como {{participante}} para insertarlo en el cursor. Al generar el certificado, cada marcador se reemplaza automáticamente con los datos del participante correspondiente.
8
Saltos de línea y párrafos en el texto
Enter simple crea una nueva línea dentro del mismo párrafo (útil para listas o separaciones leves). Enter doble crea un párrafo nuevo con separación visual entre bloques de texto. Usa el slider "Tamaño del texto interno" (70%–150%) para escalar el cuerpo completo del certificado sin afectar los títulos ni el nombre del participante.
⚠ Importante: No incluyas el nombre de la institución ni el nombre del participante en el texto del editor — las plantillas ya los muestran visualmente de forma destacada. El texto del editor es el cuerpo descriptivo del certificado.
📄 Exportación de certificados
9
Vista previa en tiempo real
El panel derecho muestra el certificado actualizado en tiempo real. Selecciona un participante del menú desplegable para ver su certificado personalizado. Usa los controles de zoom para acercar o alejar la vista.
10
PDF individual
En el Paso 6, haz clic en Generar PDF para descargar el certificado del participante actualmente visible. El archivo se nombra automáticamente: Certificado_NombreParticipante.pdf
11
Exportación masiva en ZIP
El botón Generar ZIP genera un PDF por cada participante de la lista y los empaqueta en un archivo .zip listo para descargar. Una barra de progreso muestra el avance en tiempo real. Para lotes grandes (100+ participantes) el proceso puede tardar varios minutos.
💡 Rendimiento: Para lotes mayores a 50 participantes, se recomienda usar un computador de escritorio con buena conexión. La generación de PDFs es intensiva en procesamiento del navegador.
📧 Envío por correo (Google Apps Script)
12
Configuración inicial (una sola vez)
En el Paso 6, sección "Envío Masivo por Correo", haz clic en ⚙ Configurar. Sigue los 5 pasos que aparecen: crea un script en script.google.com, pega el código, impleméntalo como aplicación web y pega la URL generada en CertiFlow. Esta configuración es permanente — no necesitas repetirla.
13
Enviar certificados por correo
Configura el asunto y mensaje del correo con marcadores dinámicos. Usa el filtro de destinatarios para enviar a todos, solo los que tienen email, o solo los seleccionados. Haz clic en Enviar a todos y confirma. Los correos se envían con una pausa de 600ms entre cada uno para respetar los límites de Gmail.
⚠ Límites de Gmail: Cuenta gratuita: 500 correos/día. Google Workspace: 1500/día. Para eventos de más de 500 personas, distribuye el envío en dos días o usa múltiples cuentas de Google.
💾 Guardado y persistencia
14
Guardar proyecto
Haz clic en 💾 Guardar en la barra superior para guardar todos los datos (configuración, participantes, texto, plantilla, logos y firmas) en el almacenamiento local del navegador. El proyecto se restaura automáticamente la próxima vez que abras la app en el mismo navegador.
15
Limpiar proyecto
El botón 🗑 Limpiar elimina todos los datos y reinicia la aplicación. Se pedirá confirmación antes de proceder. Esta acción es irreversible.
💡 Nota: Los datos se guardan en el navegador (localStorage). Si borras el caché del navegador o usas un dispositivo diferente, necesitarás reconfigurar el proyecto. Para respaldo permanente, exporta el ZIP y conserva el archivo CSV de participantes.
