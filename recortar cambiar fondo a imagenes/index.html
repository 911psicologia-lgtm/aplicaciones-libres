Know-how

Para cambiar el fondo de una foto común: primero intenta Quitar fondo claro. Luego elige color. Si el fondo es complejo, usa recorte manual alrededor del objeto.

Cargar imagen desde URL

Algunas URLs bloquean la exportación por seguridad del navegador. Para mejores resultados usa archivo local.
